- Added P10–P90 ensemble spread for 2030, 2050 and 2100.
- Added conditional NASA PyGEM-OGGM country glacier projections.
- Added CSV, JSON and BibTeX exports, print/PDF view and SHA-256 provenance.
- Added an explicit physical-climate/HFO boundary and review protocol.
